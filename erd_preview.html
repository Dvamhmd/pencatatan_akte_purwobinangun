02

Kamus Data: Entitas Pengguna & Kependudukan

📋 Tabel 1: users (Akun Warga & Petugas Admin) Primary Model: App\Models\User
Menyimpan data otentikasi login serta profil kependudukan warga desa yang terhubung dengan NIK dan Kartu Keluarga.
Nama Kolom Tipe Data Atribut / Index Keterangan & Logika Bisnis
id bigint unsigned PRIMARY KEY, Auto Inc Identifier unik record pengguna.
role varchar(255) Default: 'warga' Peran pengguna dalam sistem: admin atau warga.
nik varchar(16) UNIQUE, Nullable Nomor Induk Kependudukan 16 digit warga (kredensial login warga).
family_card_no varchar(16) INDEX, Nullable Nomor Kartu Keluarga (KK) 16 digit untuk scoping akses data.
name varchar(255) NOT NULL Nama lengkap pengguna sesuai KTP/KK.
birth_place, birth_date varchar / date Nullable Tempat dan tanggal lahir warga.
gender enum('L','P') Nullable Jenis kelamin (L = Laki-laki, P = Perempuan).
family_relationship varchar(100) Nullable Kedudukan dalam keluarga (Kepala Keluarga, Istri, Anak, dll).
doc_family_card varchar(255) Nullable Path berkas upload foto / scan Kartu Keluarga asli.
phone, email varchar(20/255) Email UNIQUE Kontak pemohon untuk notifikasi WhatsApp & Email otomatis.
status enum Default: 'pending' Nilai: pending, active, rejected, archived.
verified_at, verified_by timestamp / varchar Nullable Waktu verifikasi dan nama petugas admin yang memvalidasi akun.
📋 Tabel 2: family_members (Anggota Keluarga Warga) Primary Model: App\Models\FamilyMember
Menyimpan daftar seluruh anggota keluarga yang tercantum dalam Kartu Keluarga pengguna untuk fitur auto-fill.
Nama Kolom Tipe Data Atribut / Index Keterangan & Logika Bisnis
id bigint unsigned PRIMARY KEY, Auto Inc Identifier unik record anggota keluarga.
user_id bigint unsigned FOREIGN KEY (users.id) ID akun kepala keluarga / pemohon utama. ON DELETE CASCADE.
family_card_no varchar(16) INDEX, Nullable Nomor Kartu Keluarga anggota.
nik, name varchar(16/255) NIK: Index, Nullable Nomor NIK dan Nama lengkap anggota keluarga.
birth_place, birth_date varchar / date Nullable Tempat dan tanggal lahir anggota keluarga.
gender enum('L','P') Nullable Jenis kelamin anggota keluarga.
family_relationship varchar(100) Nullable Status hubungan (Kepala Keluarga, Istri, Anak, Cucu, Orang Tua).

Nama Kolom Tipe Data Atribut / Index Keterangan & Logika Bisnis
id bigint unsigned PRIMARY KEY Identifier unik data permohonan akte kelahiran.
user_id bigint unsigned FOREIGN KEY (users.id) Relasi ke akun pemohon (ON DELETE SET NULL).

04

Permohonan Perubahan Profil & Integritas Relasi

📋 Tabel 5: profile_update_requests (Permohonan Update Profil & Keluarga) Primary Model: App\Models\ProfileUpdateRequest
Menampung permohonan perubahan biodata diri dan anggota keluarga oleh warga sebelum disetujui petugas kalurahan.
Nama Kolom Tipe Data Atribut / Index Keterangan & Logika Bisnis
id bigint unsigned PRIMARY KEY Identifier unik permohonan perubahan profil.
user_id bigint unsigned FOREIGN KEY (users.id) Relasi ke akun warga pemohon. ON DELETE CASCADE.
name, birth_place, date varchar / date Nullable Data profil baru yang diajukan.
doc_family_card varchar(255) Nullable Path scan Kartu Keluarga terbaru sebagai bukti perubahan.
family_members_data json Nullable Struktur JSON array berisi daftar anggota keluarga baru.
status enum Default: 'pending' Status: pending, approved, rejected.
admin_notes, processed_by text / varchar Nullable Catatan verifikator dan petugas yang memproses.
🛡️ Integritas Referensial (Foreign Keys)
  • Cascade on Delete: Menghapus user akan otomatis menghapus family_members dan profile_update_requests.
  • Null on Delete: Menghapus user akan menjaga integritas histori akta (birth_certificates & death_certificates) dengan mengubah user_id menjadi NULL.
⚡ Sinkronisasi Transaksional (DB::transaction)
  • Saat permohonan profil disetujui (Approve), sistem secara atomik memperbarui tabel users, merefresh data di family_members, dan mensinkronkan nomor telepon pemohon di histori akta.
